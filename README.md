## إصلاح معاينة المرفقات (v3)

### المشكلة
الضغط على أيقونة المعاينة 👁️ في نافذة «📎 مرفقات الموعد» كان **يُنزّل الملف** بدل عرضه داخل التطبيق.

### السبب الجذري
1. جميع المرفقات مخزَّنة كـ `path` (مسار داخل المستودع) — لا يوجد `data` فيها إطلاقاً.
2. الكود القديم (`previewFileFixed`) كان يجلب الملف ثم يحوّله `blob → data URL → blob`،
   فيحتفظ الـ Blob بنوع **MIME خاطئ**؛ لأن GitHub يخدم `raw.githubusercontent.com`
   بنوع `text/plain; charset=utf-8` أو `application/octet-stream` مع
   `X-Content-Type-Options: nosniff`.
3. تصحيح النوع لم يكن يعمل إلا مع `application/octet-stream` **بالضبط** — فلا يلتقط
   `text/plain`، ويبقى الـ Blob من نوع غير PDF.
4. ملف PDF داخل `<iframe src="blob:...">` بنوع غير `application/pdf`
   ⇒ **المتصفح يُنزّله بدل عرضه**.

### الحل (الكتلة `previewFileV3` في آخر `index.html`)
| # | التغيير |
|---|--------|
| 1 | جلب الملف كـ `Blob` مباشرة — بلا رحلة `data URL` الهدرية. |

| 3 | عرض PDF **داخل التطبيق** عبر `pdf.js` على `<canvas>` مع تنقّل بين الصفحات («السابق / التالي» + عدّاد «صفحة X من Y»). |
| 4 | عرض الصور والفيديو/C��وت/النصوص داخل النافذة نفسها. |
| 5 | سلسلة مصادر بديلة عند تعذّر الجلب (`raw.githubusercontent.com` ← `github.com/.../raw/` ← `cdn.statically.io`) + رسالة خطأ عربية واضحة. |
| 6 | زر «⬇️ تحميل» يبقى متاحاً **بضغطة صريحة فقط** — المعاينة نفسها لا تُنزّل شيئاً. |

### التراجع
الكتلة مستقلة تماماً: احذفها من آخر `index.html` (من
`<!-- معاينة المرفقات — الإصدار v3` حتى `</script>` الختامي) لترجع السلوك السابق.

## النشر
- **GitHub Pages**: يُبنى تلقائياً من فرع `main` عند كل دفع —
  <https://anafwest.github.io/appointment-system/>
- **Firebase Hosting** (`anafwest-appointments.web.app`): يُنشر من
  `anafwest/appointments-riyadh` عبر `.github/workflows/deploy.yml`، ويحتاج سر
  `FIREBASE_TOKEN` أو `FIREBASE_SERVICE_ACCOUNT` في إعدادات ذلك المستودع.
