# الخادم الداخلي — نظام المواعيد

خادم Node.js **بدون أي مكتبات خارجية**، يشغّل نفس الصفحات ويحفظ البيانات في ملف JSON
داخل الشبكة الداخلية، ويعمل بالتوازي مع Firebase (الوضع المزدوج).

## التشغيل

```bash
node server/server.js
# ثم افتح: http://<عنوان-الخادم>:8080
```

متغيرات اختيارية:

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `8080` | منفذ الخادم |
| `HOST` | `0.0.0.0` | العنوان الذي يستمع عليه |
| `DATA_DIR` | `server/data` | مجلد البيانات (db.json) |
| `ADMIN_EMAIL` | `admin@local` | بريد مدير النظام الأول |
| `ADMIN_PASSWORD` | `Admin@12345` | كلمة مرور مدير النظام الأول |

> عند أول تشغيل يُنشأ حساب مدير النظام تلقائياً. **غيّر كلمة المرور فوراً.**

## كيف يعمل الوضع المزدوج؟
- عند فتح أي صفحة، يفحص النظام وجود `/api/health` على نفس الخادم.
- وُجد → **وضع محلي**: كل البيانات من الخادم الداخلي، تحديث لحظي عبر SSE، وشارة «وضع محلي».
- لم يوجد → **وضع Firebase** كما هو (العمل خارج الشبكة الداخلية).
- للتحويل اليدوي: أضف `?mode=firebase` أو `?mode=local` إلى رابط الصفحة (يُحفظ في المتصفح).

## المزامنة مع Firebase
عند توفر الإنترنت على جهاز الخادم:

```bash
node server/sync-firebase.js status   # مقارنة فقط
node server/sync-firebase.js push     # المحلي ← Firebase
node server/sync-firebase.js pull     # Firebase ← المحلي
```

حمّل ملف `service-account.json` من Firebase ← Project settings ← Service accounts
واحفظه في `server/service-account.json` (مستثنى من Git).
قاعدة الترجيح: أحدث `updatedAt` يفوز، ولا تُحذف أي بيانات من السحابة.

## النسخ الاحتياطي
كل البيانات في ملف واحد: `server/data/db.json` — انسخه دورياً (مهم).
